# 第十一章 时间轴规划：1个月、3个月、6个月、1年、3年

规划原则用你自己的话：先跑通一个闭环，才有资格谈规模化。每个阶段都有验收标准，验收不过，下一阶段自动降级为重跑本阶段。所有日期以2026年7月26日为起点。

## 11.1 一个月冲刺（2026年8月）：止血与建账

八月只做四类事：修复低成本高杀伤的风险、建立唯一口径、启动书、不接新坑。

**第一周（7.27至8.2）：口径与资产盘点周。**
- 建立《王磊唯一口径表》：服务企业数、学员数、案例清单、每个案例可对外讲的数字，全部核实到"敢被截图对照"的水平。今后一切物料从表取数。（对冲R3，半天工作量）
- 把本次导出的对话数据、全部提示词系统、课件、Skill包归档进私有Git仓库，建立季度导出日历提醒。（对冲R6，一天工作量）
- 从否定语录整理《交付验收标准v1.0》：课件、长图、方案、合同四类交付物，每类十条硬标准。（细节二，半天）
- 预约一次全面体检，日期写死在八月内。（R1，一小时）

**第二周（8.3至8.9）：价格政策与合同底盘周。**
- 写《价格政策v1.0》一页纸：培训、顾问、产品三线的挂牌价、山西惠价的适用条件与折扣上限（建议七折封底）、赠送条款的白名单（案例权可换折扣，不可换长期维护）、全款与分期规则。今后报价只许查表，不许现场发明。
- 找本地律师做两件事：三份合同模板（培训、顾问、产品）年检；宣传物料合规过一遍。（R8，预算五千内）

**第三周（8.10至8.16）：书的立项周。**
- 《企业AI商学院》立项：以GAIC三十页演讲稿为骨架扩写目录，三十页就是三十章的雏形。联系机械工业出版社的既有编辑关系（你是他们的合著作者，这是现成通道）。
- 定写作制度：每周两个早晨各九十分钟，AI辅助整理素材，你口述观点。目标2027年一季度交稿。

**第四周（8.17至8.31）：派活融合试点启动。**
- 选一个现有顾问客户（建议龙晟达，合同期内且关系热），把交付过程搬进派活：任务下达、数字员工执行、交付审计全部走平台。你自己当产品经理记录所有卡点。
- 想法停车场建立：把CommunityClaw、Marvis复刻、AI版Boss直聘等全部构想写进去，封存。

**八月验收标准：** 口径表、验收标准、价格政策三份文件存在且已使用至少一次；体检完成；书的目录与出版社沟通发生；一个真实客户在派活上跑了至少一个完整任务闭环。五项过四项算过。

## 11.2 三个月（至2026年10月底）：把"王磊的课"变成"可复制的课"

**九月：认证课的原型。**
- 把企业AI商学院方法论做成标准两天课《企业AI商学院·启动营》：固定课纲、固定练习、固定交付模板（学员离场时带走自己企业的30天闭环方案）。这门课今后不再定制，只换案例。
- 招聘交付助理一名（大同本地，要求：文字功底加执行力，不要求AI经验，你亲自用训练公众号大师的流程训练他）。月成本预算六千到一万。
- 输入日制度启动：每周四下午封闭，只输入不输出。

**十月：定价上探与第二个平台客户。**
- 用新价格政策签一单全国价培训（长三角或珠三角，走360或润米渠道），目标单价8万以上，验证"同样的课在对的市场值多少钱"。
- 派活迁入第二个顾问客户（建议酒道馆，小而完整）。整理试点一的卡点清单交给技术顾问评估。
- 聘请兼职技术顾问（短板二配置），首个任务：评审派活的迁移卡点与AI Memory Assistant的残值（修复、重做还是核销）。

**三个月验收标准：** 启动营课纲与教材v1.0存在且授过一次；交付助理入职且完成第一个60分初稿；一单8万以上全国价成交或进入合同流程；派活上有两个真实客户；技术顾问到位。五项过四项。

## 11.3 六个月（至2027年1月底）：第一个"离开你也能转"的闭环

**十一月至十二月：商学院首个付费共建。**
- 从现有客户里选一家（龙晟达或米兰软装体系）签下第一单"企业AI商学院年度共建"：年费制（建议15到25万/年），交付内容就是你方法论的运营化（月度任务发现、季度复训、SOP库与数字员工库建设、指标看板），全部在派活上运行。这一单是你飞轮第三环的首次真实转动，价值远超金额：它定义了你未来的主力商品。
- 书稿完成50%。
- 二号讲师启动：从你的OPC学员或行业内找一名有讲台能力的人，用启动营的标准课纲培养，目标2027年上半年能独立交付启动营的一半模块。

**2027年一月：年度结账与系统体检。**
- 全年财务复盘（此时你应该已有月度管理报表三个月以上）：四条收入线的真实毛利排序，砍掉毛利最低且不产生资产的活动。
- 对话数据、课件、Skill全量备份的第二次执行。
- 家庭储备金检查：是否达到18个月覆盖，未达到则2027年的产品投资预算削减至达标为止。（R9）

**六个月验收标准：** 一单年度共建合同生效且首月运营发生在派活上；书稿过半；二号讲师完成首次试讲；月度管理报表连续三个月；家庭储备金规则成文。五项过四项。

## 11.4 一年（至2027年7月底）：品牌立起来

**2027年二季度的三大战役：**

**战役一：书出版。** 《企业AI商学院》上市，配套动作打满：刘润生态的推荐位、360渠道的企业侧分发、waytoAGI的社区首发、你自己内容系统的三个月火力覆盖。书的目标不是版税，是把"企业AI商学院"这个词和王磊绑定。

**战役二：认证体系首期。** 启动营升级为"认证AI商学院教练"首期班（面向培训师、咨询师、你的OPC高阶学员），学费两到三万，首期目标15到20人。教练体系是你规模化的杠杆：他们交付初阶课，你收授权费与派活订阅分成，你本人退到高阶课与标准维护。
- 此时交付结构应为：助理产初稿、AI做生产、你做验收与出场，你的现场时间占交付总时间应降到30%以下。

**战役三：派活的商业化定型。** 产品定位固化为"AI商学院运营系统"，定价随共建合同与教练体系打包（不单卖），目标此时有8到12家企业在平台上月活运营。技术投入维持外购模式，除非订阅收入证明可以养一名全职工程师。

**一年验收标准（这是最重要的一次验收）：**
- 收入结构：订阅型收入（共建年费加派活订阅加认证授权）占比达到25%以上。
- 键人测试：你连续休假两周，业务不塌（有讲师能上课、有助理能交付、有平台在运行）。
- 品牌测试：搜索"企业AI商学院"，你的内容占据首屏。
- 健康测试：两次年度体检完成，无恶化指标；周工作时间从70小时压到55小时以内。
- 财务测试：年收入不低于2026年（转型期允许不增长，但不许下降），毛利率上升。
五项必须过四项，其中键人测试为否决项：不过则2027下半年冻结一切新扩张，专补组织。

## 11.5 三年（至2029年中）：从个人品牌到行业标准

三年展望不排月度动作，只定终局形态与三条曲线：

**曲线一：标准曲线。** 2027年书立标准，2028年认证教练破百人、发布《企业AI商学院成熟度评估模型》（把你的五层模型做成可评分的行业标尺，配套评估服务），2029年成为这个细分领域事实上的标准制定者。终局检验：别的咨询公司投标时引用你的模型。

**曲线二：系统曲线。** 派活从教具长成生意：2028年目标50家企业年活跃、订阅收入养得起3人小团队；2029年做决策：独立融资扩张、被并购、或保持利润奶牛形态。三个选项都是赢，前提是它一直贴着你的商学院生态长，不脱轨去打平台战争。

**曲线三：自由曲线。** 你的个人时间配置到2029年应为：40%高阶内容与标准（书的再版、模型迭代、头部演讲）、20%关键客户与生态关系、20%输入与实验（保持你的一线手感，这是你区别于退休大师的关键）、20%留白（家庭、健康、以及你的玄学社交）。收入结构：被动与半被动（版税、授权、订阅分成）占50%以上。

**三年终局的一句话验收：** 2029年的某一天，一家你从未接触过的企业，通过你的认证教练、用你的书里的方法、在派活上建成了自己的AI商学院，全程没有花你一分钟。那一天，你就完成了从"最能干的员工"到"可以被复制的系统"的升级。

## 11.6 各阶段的资源约束提醒

- 全程不融资（教育与咨询现金流足以自养，融资只在曲线二2029年决策点考虑）。
- 全程团队不超过5人（助理、二号讲师、技术顾问、运营，加你）。人不是越多越好，你的组织能力是短板，小队形是保护你。
- 任何新产品构想继续进停车场，每季度评审只放行一个，放行标准：直接服务三条曲线之一，否则再好也不做。
