# 第十二章 个人操作系统改造：把你自己当成最重要的那个岗位

你给企业做岗位五拆解，这一章把你自己的岗位拆了：角色、输入、判断、输出、验收，逐项重新配置。

## 12.1 时间系统：从"响应式"到"块状化"

你现在的日程是响应式的：客户约就见、活动来就接、晚上补产出。改造成四类时间块，写进日历并像客户会议一样保卫：

- **成交块**（周一、周二白天）：见客户、谈判、演讲。你的时薪最高的活动，集中排。
- **生产块**（周三、周五上午各九十分钟起）：书稿、课件、标准。规则：生产块产出的必须是"三年后还能用的东西"，为明天的会做的东西不许占用生产块。
- **输入块**（周四下午，雷打不动）：拆解、精读、客户深访。手机免打扰。
- **留白块**（周末至少一个整天）：家庭、健康、玄学社交。留白块的KPI是"没有产出"。

夜战不禁止（禁不掉），但立一条红线：**连续两晚超过零点，第三晚强制休整。** 你的产出质量数据支持这条线：你自己都发现过深夜产出的错别字率明显更高（"咋都是错别字呢"多数发生在深夜会话）。

## 12.2 健康系统：当成合规项目管理

用你自己的话说，这是"悬着的剑"级别的合规项目：
- 年度全面体检两次（八月与二月），项目里加上心血管专项（你的工作模式的标准风险区）。
- 处方药零自配：任何药物组合问题只问医生药师。AI的正确用法是帮你整理症状时间线和问诊问题清单，帮你把三分钟的门诊问出十五分钟的效果。
- 出差规则：单程超过四小时的行程，落地当晚不排工作局。3月那次连夜改签就是这条规则的反面教材。
- 一项不需要意志力的运动锚点：比如每天送孩子上学步行往返，或固定晨间二十分钟。选一个能和家庭时间合并的，你这种人只有"顺便"能坚持。

## 12.3 数据与安全系统：你的第二大脑要有产权

- 季度导出：对话记录、提示词、课件、Skill，全量归档进私有Git仓库（已在八月计划里，这里强调制度化：日历提醒加助理执行）。
- 客户档案结构化：从AI对话记忆里搬出来，建一张你自己的客户表（客户、决策人、历史合同、报价、续约日期、案例授权状态）。这张表同时就是AI Memory Assistant产品的种子需求文档，你自己先当用户。
- 账号卫生：核心业务账号独立、不共享，开启一切可用的两步验证；付费与数据所在的账号，恢复邮箱和手机必须是你本人的。
- 对外物料的客户信息：案例展示遵守你自己Skill里的规矩（不虚构、已授权），把"案例授权"写进合同模板（酒道馆那种"做成案例对外展示"的条款就是正确姿势，推广到所有合同）。

## 12.4 学习系统：保卫你的认知库存

- 输入块的内容配比建议：40%客户业务纵深（去客户现场看真实工作流，这是你的课件案例的原产地）、30%AI前沿（保持你"第一时间拆解新东西"的手感）、30%跨界（商业史、组织理论、你喜欢的史学分析，这些是你金句的地下水）。
- 每季度一次"深度拆解发表"：把输入块最好的一次拆解写成长文公开发表。倒逼输入质量，顺便喂养声浪系统。
- 每半年更新一次《交付验收标准》与《价格政策》版本号。你的标准也需要迭代，和你的提示词系统同一个道理。

## 12.5 决策系统：给自己装上你给派活设计的那套流程

派活的AI会议机制是"提案→反向验证→决策→执行"。你的个人重大决策（超过5万的投入、新产品线、超过三个月的承诺）走同样流程：
1. 提案写一页纸（你本来就会写）。
2. 反向验证：至少一名人形反驳者过目（第9.3节的委员会），AI扮演最强反方再攻击一轮。
3. 冷却四十八小时（专治你的"格局升级"冲动）。
4. 决策与执行，写明验收日期。

## 12.6 内容系统：从"高产"转向"复利"

公众号大师系统继续跑，但内容战略配比调整：
- 50%服务主干A：企业AI商学院的方法论、案例、书的预热内容。
- 20%你自己的一手实践（细节一的"王磊如何管理AI"系列，这是你独家且不可抄袭的内容线）。
- 20%失败与踩坑复盘（低估三的信任构建线）。
- 10%自由发挥（社会评论、玄学、你的锋利趣味，保持人味）。
标题继续狠，但守住你自己的禁用词表和Truth Ledger：狠在洞察，不狠在焦虑。这是你和你骂的人的边界。
