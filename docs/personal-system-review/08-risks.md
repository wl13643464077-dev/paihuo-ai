# 第七章 风险清单：按发生概率乘杀伤力排序

用你自己的语言：这是你这家"一个人的公司"的风控报表。每条风险给出触发信号与对冲动作，规划部分会把对冲动作排进时间轴。

## R1 键人风险（概率：确定存在；杀伤力：毁灭性）

你的收入、交付、品牌、客户关系100%绑定你本人的健康与在场。已有一次带病连轴的实际警告（3月）。触发信号：任何持续两周以上的健康问题，等于全线收入归零加违约风险。对冲：体检制度化、二号讲师培养、课程资产化（你不在场也能卖）、顾问合同里加不可抗力与替代交付条款。

## R2 产品线过散（概率：已发生；杀伤力：高但慢性）

十二条产品线共享你一个人的注意力，每条线都在"能演示、难复制"的状态徘徊。慢性杀伤的机制：每条线都需要维护成本（酒道馆的一年维护、龙虾盒子的售后承诺、各版本课件的更新），维护承诺的总和正在逼近你的产能上限，届时新增长必须靠透支。对冲：第十一章的三层分级（现金层、资产层、停车场）。

## R3 数字口径与人设一致性（概率：中；杀伤力：高且突发）

第六章细节三与细节七的组合风险。你的行业地位越高，被对照检查的概率越大。对冲成本极低（唯一口径表加人设对齐），是所有风险里性价比最高的修复。

## R4 技术采购再踩坑（概率：高；杀伤力：中）

20万学费已付，行为模式未改。你的产品雄心（派活、PowerOffice、复刻Marvis级产品）决定了你未来三年还要发生数十万级的技术投入。对冲：软件监理机制，任何超5万的开发采购必须有独立评审、里程碑验收、源码与数据归属条款。

## R5 现金流结构风险（概率：中；杀伤力：中）

你的收入以项目制与预付款为主，好处是现金前置，坏处是收入的可预测性差：没有订阅型收入垫底，淡季就是零。加上你"先付全款再干活"的条款在客户升级为大企业时不可复制（大企业只走对公账期）。对冲：把顾问模式改造成年度陪跑订阅（第十二章），三年内把订阅型收入做到总收入40%。

## R6 数据资产托管风险（概率：低到中；杀伤力：高）

第六章细节六。全部商业记忆在第三方服务器，账号与网络路径不稳定。对冲：季度导出制度、客户档案本地结构化、核心IP（提示词系统、课件、Skill）进你自己的Git仓库（你已经有paihuo-ai仓库的工程习惯，扩展即可）。

## R7 生态位窗口关闭（概率：中期必然；杀伤力：高）

"AI培训+顾问"的红利窗口预计两到三年。窗口关闭时市场只留下三种人：有软件产品的、有行业纵深的、有教育品牌的。你必须在窗口内把至少一样做到"离开你也能卖"。这就是三年规划的顶层命题。

## R8 合规与合同风险（概率：低；杀伤力：中到高）

你的合同全部由AI起草、你自己验收，而你没有法律验收能力；你的宣传物料里含有大量客户名称与战绩数字（部分口径漂移）；你同时在推动"补贴申请"类业务（人社厅OPC补贴、科技厅算力申请），这类业务的合规边界需要专业把关。你自己写过"合规合法是悬着的剑"。对冲：找一位按次付费的本地律师做年度合同模板审查与物料合规审查，一年两次，预算万元以内。

## R9 家庭账户风险（概率：未知；杀伤力：高）

数据里完全看不到你的个人财务防火墙：公司与个人账是否分离、有没有家庭应急储备、20万级别的投资亏损对家庭现金流的实际冲击。看不到不等于没有，但"看不到"本身就是风险信号，因为你所有其他领域都留了数据痕迹。对冲动作只需一条：家庭储备金独立（覆盖18个月家庭开支），任何产品投资不得动用。
