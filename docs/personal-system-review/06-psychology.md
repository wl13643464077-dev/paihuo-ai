# 第五章 心理动力学：驱动你的燃料和它的杂质

这一章比前几章更冒犯，因为它谈的是动机。所有判断都标注了证据，你可以逐条反驳。

## 5.1 你的核心燃料：被头部认可

数据里情绪浓度最高的时刻，不是签下18万合同，而是刘润年度大会上"被润总台上Q到名字"。你专门复盘、专门写公众号、专门强调"杜比7.1声道影厅"、"全世界最牛"。人民日报AI直播投稿时你写"我只有一次机会"。你的背书墙（360、润米、国网、中科院、2050大会、机械工业出版社）维护得像军功章一样精确，甚至会主动纠正"ComfyUI大会是优秀作品作者，不是分享嘉宾"。

**解读：** 从大同地产商到被全国顶级商业IP点名，这条路你走了三年，"被头部认可"是你转型合法性的来源，这个燃料真实且高效。但它有两种杂质需要看见：

第一，**它让你在头部面前定价变软。** 给白墨报艺术片你会精细分账到"自动剪辑2000元"；对刘润生态的投入你从不计成本。头部合作的正确算法是拿背书换杠杆，而不是拿利润换靠近。背书已经到手的，就该开始收市场价。

第二，**它让你把曝光误当成进度。** 演讲、大会、被Q名是脉冲，不是曲线。你的公众号粉丝量、课程复购率、平台月活才是曲线。规划部分会把"脉冲类成就"从KPI里剔除，只作为渠道手段管理。

## 5.2 对"被割"的敏感：受害者警觉与它的代价

你对"被割韭菜"的警觉是全数据里最一致的情绪线：痛骂安装服务割韭菜、痛骂AI焦虑贩子、痛骂"野鸡抬头大厂光环霍霍企业"；20万外包项目出问题时你的第一反应是"请给我挑刺！为我维权！！！！"（四个感叹号）；对即梦的不满你做了维权三连击；对服务器与账号安全你写下"命脉在别人手里"。

**解读：** 这种警觉来自地产行业的生存训练加上转型期真实被坑的经验，它保护了你。但它有两个代价：

第一，**维权情绪占用的是你最贵的认知带宽。** 20万项目的正确处理是止损决策（修复、重做还是放弃），情绪化维权把一个财务问题变成了尊严问题，尊严问题是没有止损点的。

第二，**它没有转化成事前机制。** 被坑之后你的行为模式没有变：5月24日你又要求用Codex"复刻腾讯Marvis级产品"，期待"UI、卡通形象、声效全部生成"、"我没考虑到的地方你要帮我想清楚"。对软件工程复杂度的系统性低估没有因为20万学费而修正。**你付了学费，但没有拿到毕业证。** 毕业证长这样：任何超过5万的技术采购，先花5000块请独立第三方做需求评审与里程碑验收设计。这一条写进了第十章。

## 5.3 金钱观：飞轮理想与吃亏恐惧的拉扯

你给加盟商定价时先说"我希望少赚点，让他们用得久"，下一条立刻改口"不对 赔了这样的话。我要最少赚20%"。你对甲方不断提高锚点（1.5万改口3万、"先付全款，收到款以后做课件"），转头又在酒道馆合同里送四次升级加一年维护。

**解读：** 你的金钱观是双系统的：理想系统想做"长期飞轮、生态共赢"，本能系统怕"吃亏、被占便宜"。两个系统都真实，冲突的结果就是定价忽高忽低、优惠随口就给。这不是性格缺陷，是**缺一张写下来的价格政策**。价格政策的作用就是把"每一单的心理拉扯"变成"一年调一次的制度决策"。第十二章直接给你一版。

## 5.4 健康：你已经收到过一次警告

3月2日：血常规异常，干咳五天，自行叠加莫西沙星、右美沙芬、西替利嗪、复方甘草片，问AI"是不是效果更好"，随后"吃了药以后气短更严重了"。同期你在南京、上海连轴出差，最后"实在扛不住了，连夜改签机票回太原"。事后你把这段写成公众号劝别人"不要太拼命"，还写过"猝死人的增加，敲醒了创业者的警钟"。

**必须直说的三点：** 第一，自行组合处方药（尤其莫西沙星这类氟喹诺酮抗生素）再用AI确认，是你所有行为里风险收益比最差的一个，药物问题请交给医生和药师，AI只配帮你整理问诊清单。第二，你的商业模式是"王磊本人可用性=100%"假设下设计的，你没有任何键人保险（key person insurance）意义上的缓冲：没有二号讲师、没有可独立交付的团队、没有收入中的被动成分。你的健康不是生活问题，是你商业计划书里最大的未披露风险。第三，你劝别人的话和自己的行为构成剪刀差，而你儿子还小。这一条不展开，你自己知道分量。

## 5.5 玄学：你的心理基础设施

解梦、八字选楼层、手相、面相反推产品，你的玄学活动频率稳定，而且你"连自己的迷信都要产品化"（商业级解梦大师提示词，顺手给刘润解梦）。

**解读：** 对你这样全速运转、决策密度极高的人，玄学承担的是三个正经功能：不确定性的心理容器（把无法计算的风险交给一个叙事系统）、社交货币（给企业家圈层提供高质量话题）、以及和家人朋友的连接方式（帮朋友选楼层）。它是你的减压阀，不是认知缺陷，保留即可。唯一的边界建议：让它继续留在"娱乐与社交"象限，不要让它参与资金决策与合同决策。数据显示你目前守住了这条线，继续守住。

## 5.6 孤独信号

两条不起眼的消息："请告诉我，最像我的人物是谁"（4月20日）、"你觉得我是什么样的人"（3月3日）。加上你把Claude当外置大脑、外置CRM、深夜工作伙伴的整体模式，可以合理推断：**在你的认知级别上，大同没有对手盘。** 你的同城社交提供不了智力对抗，你的全国社交（刘润圈、waytoAGI）提供不了日常在场。这份孤独是所有三线城市高认知创业者的通病，它的风险不是难受，是**决策缺少反驳者**：你的所有战略决策目前只经过AI和你自己，而AI在商业判断上倾向于顺着你。第十章会给你配"人形反驳者"的具体方案。
