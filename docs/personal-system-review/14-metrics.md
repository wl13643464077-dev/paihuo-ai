# 第十三章 指标看板与季度自检

## 13.1 你的个人ROI账本（月度四数）

你教老板看四个数字，你自己的版本：

1. **现金余额与订阅收入占比**：订阅占比是战略转型的唯一北极星，从现在的约0%走向三年后的50%。
2. **本人现场小时数**：你亲自到场的交付小时，目标逐季下降。它降，说明系统在长大；它升，说明你又在用命换钱。
3. **资产新增数**：本月新增的"三年后还能用的东西"（书稿章节、标准课件、认证教材、平台功能、可复用案例）。为明天生产的东西不算。
4. **续约与转介绍占新签比**：飞轮健康度的真实指标，替代"新签数"这个虚荣指标。

## 13.2 季度自检问卷（每季度末，一小时，白纸作答）

1. 这个季度我新签的承诺，有几个是想法停车场放行的，有几个是绕过停车场直接答应的？
2. 我的三份治理文件（口径表、验收标准、价格政策）这个季度被实际使用了几次？被违反了几次？
3. 键人测试：如果我明天住院两周，哪些交付会违约？这个清单比上季度长了还是短了？
4. 我的输入块被侵占了几次？我最近一次让自己认知震动的输入是什么？
5. 我对孩子和家人的承诺，兑现率和我对客户的承诺兑现率，哪个高？
6. 数字口径：本季度所有对外物料的数字，敢不敢被并排截图？
7. 我这个季度骂过的行业乱象，我自己的业务里有没有影子？
8. 三条曲线（标准、系统、自由）各前进了什么？哪条停了？为什么？

第五题和第七题最疼，也最重要。

## 13.3 红线清单（触发即停）

- 连续两个月订阅收入占比下降且现场小时数上升：停止接新培训单一个月，强制回到资产生产。
- 任何健康指标恶化：所有规划自动降速50%，无需讨论。
- 任何一次数字口径被外部质疑：全渠道物料72小时内核查修正，先于任何辩解。
- 技术采购未经技术顾问评审即签约：合同作废重谈，无论多急。
