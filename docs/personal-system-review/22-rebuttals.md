# 第二十章 预演你的十个反驳

你读完这份报告一定会反驳。这一章把你最可能说的十句话提前摆出来，逐条回应。这也是给你的人形反驳者委员会的第一份会议材料。

**反驳一："我这些产品线互相赋能，不是分散。"**
回应：赋能要有账。十二条线里真实发生过交叉转化的只有三对（培训带产品单、内容带培训单、OPC带私域）。PowerClaw给EmotionClaw赋了什么能？说不出转化路径的"互相赋能"，就是舍不得的漂亮说法。判决书（第十六章）没杀掉任何真有交叉转化的线。

**反驳二："机会来了不抓，过了这村没这店。"**
回应：你的机会成本算法只算了"错过的收益"，没算"在手的稀释"。你现在每接一个新机会，都在从书和商学院的时间里扣。窗口期两到三年（R7），真正过了这村没这店的，是"企业AI商学院"这个词的定义权。别的机会明年还有，这个位置明年可能就有人坐了。

**反驳三："涨价了本地客户就跑了。"**
回应：所以价格政策设计了双轨（挂牌价加案例价七折封底），本地盘没让你涨价，让你把"随口优惠"变成"有对价的优惠"。跑掉的那部分客户，本来就是你时薪表上的亏损项。

**反驳四："招人麻烦，AI比人好用。"**
回应：这句话前半句是你的真实体验，后半句是你的路径依赖。AI好用是因为你花了六个版本训练它。你没有用同样的耐心训练过任何一个人，所以"人不好用"这个结论的样本量是零（外包不算，那是没有验收机制的发包）。键人测试（休假两周业务不塌）AI替你过不了，因为客户买的出场是你这张脸。

**反驳五："写书太慢，公众号天天更新不是更快吗。"**
回应：文章是弹药，书是阵地。你已经证明了弹药产能，缺的是一个别人绕不开的阵地。而且书稿的素材你已经写完了（GAIC三十页就是目录），这本书对你是整理，不是创作。每周三小时，两个季度就能交稿，慢不了。

**反驳六："派活不做通用平台，格局是不是小了？"**
回应：这句"格局"就是细节八说的产能陷阱在说话。钉钉飞书的团队规模是你的千倍，通用平台是他们的主场。贴着商学院长的派活，护城河是你的方法论加你的客户关系，这个仗他们打不了。先做深一百家，再谈通用，那时你有的是数据和筹码。

**反驳七："我身体好得很，三月就是个感冒。"**
回应：三月的问题不是感冒，是"感冒加自配处方药加连轴出差加连夜改签"这个处置链。你的风控水平在业务上是一流的，在自己身体上是不及格的。而且这条是否决项：R1不需要你认同，只需要你执行（体检两次、出差规则、药物零自配）。

**反驳八："这些制度表格太繁琐，我是靠灵活吃饭的。"**
回应：六件套模板加起来的维护成本是每周三十分钟，换的是你每单几小时的心理拉扯和每年至少一次的口径风险。而且你不是讨厌制度的人，你是最爱给别人建制度的人（你给企业的交付全是SOP和验收表）。你只是没享受过当制度受益人的感觉。

**反驳九："万一书写出来没人看呢？"**
回应：书的第一功能不是销量，是资格。认证体系、共建定价、头部生态位，全都因为"有书"而单价翻倍。销量是刘润生态加360渠道加你自己声浪系统的运营问题，而运营恰好是你擅长的。最差情况：书卖得一般，但你从此是"写了那本书的人"，这个身份没有下行风险。

**反驳十："你一个AI，凭什么规划我的人生？"**
回应：凭你自己的数据。这份报告没有一条判断来自外部理论，全部来自你五个月615条消息、你的合同、你的报价、你的演讲稿和你亲手写的商业认知库。我做的只是把你自己的方法论（岗位拆解、验收标准、ROI账本）用回你自己身上。你可以推翻任何一条结论，但推翻的时候你需要拿出证据，而证据在同一批数据里。这正是你教企业的那句话：没有数字，就没有落地。
