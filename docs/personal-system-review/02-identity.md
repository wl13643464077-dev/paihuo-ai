# 第一章 你是谁：身份与轨迹的系统性还原

## 1.1 一句话定位的演变

如果把你过去几年的身份变化压缩成三个阶段：

**阶段一：地产人王磊。** 房地产开发出身，企业管理背景，积累了三样东西：对中小企业老板这个物种的深刻理解、山西本地的政企与行业协会人脉、以及一整套"项目要算账、交付要验收"的实业思维。这三样东西后来全部变成了你做AI的差异化底牌，这一点你自己未必充分意识到，后面第七章会展开。

**阶段二：转型期的学习者与共创者。** 你没有走"报个课、考个证"的常规转型路径，而是直接扎进了生态最前沿：成为waytoAGI核心共创者，参与创办白墨（AIGC影视视觉工作室，与吴锦佳合作），与机械工业出版社合著AI智能体设计书籍。这个阶段你完成了从"用AI的人"到"在AI圈有名字的人"的跨越。

**阶段三：独立AI企业顾问王磊。** 今天的你，用你自己在案例页里的话说："独立AI企业顾问，山西人，企业管理出身。"以大同为根据地，向企业客户交付培训、顾问、定制AI产品三类服务，背后站着360集团、润米咨询（刘润）、国家电网（特聘讲师）、中科院物理所、广东美业AI委员会（副主任）这一排背书墙。

这个三段式轨迹里有一个关键事实：**你的每一次跃迁靠的都不是技术，是生态位判断。** 你在AI技术上永远不会比一线工程师强，但你在2023至2024年就判断出"企业不缺工具，缺组织方法"这个生态位，并用两年时间把自己钉在了这个位置上。这是你所有资产里最值钱的一笔。

## 1.2 资源底盘盘点

把你的资源按"财侣法地"你自己的框架过一遍：

**财（现金流结构）：** 你目前的收入是典型的顾问型现金流：培训按天收费（2天1.5万至3万一期）、顾问按月订阅（1个月3万，最少6个月一签，一次性付清）、产品按项目收费（小程序含6至7个数字员工5万、酒道馆AI运营系统3万）、大单组合（龙晟达AI顾问+OPC培训18万不打折）。此外有课程与内容资产（OPC十讲、OpenClaw企业指南161页）作为低边际成本产品。你还花过20万采购外包开发（AI Memory Assistant项目），说明你有再投资意愿，也说明你在用真金白银试错产品路线。

**侣（伙伴与网络）：** 三层结构。最外层是品牌背书（360、润米、国网、中科院、美业委员会）；中间层是生态战友（waytoAGI社区、白墨吴锦佳、机械工业出版社）；最内层是本地合伙模式：合伙人出资金和客户资源，你出IP、产品和方法论。这个内层结构是你规模化的原型机，也是你目前最脆弱的一环（第九章详述）。

**法（方法论资产）：** 这是你密度最高的资产。财侣法地→声浪→商业闭环的顶层框架；省时间、少错误、多收入、留经验的四买单话术；高频、高成本、高错误率、可验收的任务筛选四标准；角色、输入、判断、输出、验收的岗位五拆解；30天闭环、90天商学院的落地节奏；Prompt→SOP→岗位Skill→数字员工→部门工作流→企业AI商学院的六级阶梯；认知、场景、训练、资产、运营的商学院五层模型。这套东西已经完整、自洽、可教学，GAIC演讲稿就是它的成熟形态。

**地（根据地）：** 大同为核心的山西盘：本地政府关系、行业协会、国网山西、太原服装城这类区域客户。同时你有全国性的线上声量入口（公众号内容系统、waytoAGI、演讲活动：宁波360场、北京医疗AI大会、山西品牌协会圆桌）。

**声浪（你自己加的第五维）：** 公众号大师系统从1.0迭代到6.0，带情绪引擎、立场轮换、HTML截图配图、飞书同步；抖音、视频号、私域的商业自我介绍Skill；案例展示页40案例7分类。你的声浪系统的特点是"工程化"，不靠灵感靠系统。

**商业闭环（第六维）：** 培训与顾问（现金流）→定制AI工具（护城河）→企业AI商学院共建（复利增长）。这个飞轮你已经讲得很清楚，但目前真正转起来的只有第一环，第二环刚起步，第三环还停留在方法论层面。这是三年规划的主战场。

## 1.4 你所处的时间窗口

2026年年中这个时间点，对你的生态位有三个外部事实：

第一，企业AI落地从"要不要"进入"怎么做"的阶段，你押注的"组织方法"生态位正在从早期进入主流，这是顺风。你自己在公众号里也写过：Anthropic亲自下场做企业AI服务，等于替你验证了这门生意。

第二，主流的验证同时意味着巨头和大咨询公司入场，"AI培训+顾问"这个市场的窗口期不会超过两到三年，之后个人品牌顾问会被挤压到两个极端：要么有产品，要么有不可替代的行业纵深。你现在两头都布了子，但两头都还没扎穿。

第三，你的根据地山西属于AI渗透的价格洼地与信任高地：竞争少、客单价低、但关系壁垒高。这决定了你的正确姿势不是逃离山西，而是把山西当成"实验田+案例库"，把全国当成"放大器"。你实际上已经在这么做了（宁波、北京、广东的动作），只是还没有把它明确成战略。
