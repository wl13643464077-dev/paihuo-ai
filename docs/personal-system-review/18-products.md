# 第十六章 产品线判决书：十二条线逐条裁决

第十章给了取舍原则，这一章逐条执行判决。每条产品线按四栏裁决：真实状态、战略角色、判决、九十天动作。判决只有四种：**加倍、保持、降级、封存**。

## 16.1 派活 PaiHuo（paihuo.ai）：判决＝加倍

**真实状态：** 已上线，工程化程度是你所有产品里最高的（多租户、任务中心、AI会议收敛、CI与安全审查、发布流程）。但与顾问业务零融合，无真实企业客户在上面月活运营。
**战略角色：** 曲线二的主体，商学院的操作系统，你区别于所有讲师的物证。
**九十天动作：** 龙晟达与酒道馆两个客户迁入；卡点清单交技术顾问；定价并入共建合同不单卖。**红线：不做通用Agent平台，不加与商学院运营无关的功能。**

## 16.2 企业AI商学院方法论（含GAIC体系）：判决＝加倍

**真实状态：** 思想成熟度100%，产品化程度10%（只存在于演讲与定制课里）。
**战略角色：** 曲线一的主体，三年战略的绝对核心。
**九十天动作：** 书立项并完成前三分之一；启动营标准课定稿并首讲；共建合同模板拟定。

## 16.3 OPC课程体系：判决＝保持

**真实状态：** 十讲加职业提示词包，500+学员，是你的思想根据地与私域基本盘。
**战略角色：** 商学院的个人版；认证教练的生源池；内容系统的素材库。
**九十天动作：** 不做新版本，把现有十讲的交付流程交给助理标准化；学员池里筛二号讲师与首期认证班候选人。

## 16.4 公众号大师系统（1.0至6.0）：判决＝保持

**真实状态：** 你最成熟的个人生产系统，版本管理习惯良好。
**战略角色：** 声浪基建，服务书与认证体系的内容火力。
**九十天动作：** 内容配比按12.6节调整（50%商学院主线）；把系统本身的构建过程写成"王磊如何管理AI"系列的第一篇。

## 16.5 商业自我介绍Skill：判决＝保持（低维护）

**真实状态：** 工程完成度极高（64技术覆盖、双LOOP、Truth Ledger、便携包v3、验证脚本），有斯文一个完整交付案例。
**战略角色：** 获客漏斗的一环（帮企业家做介绍=最低门槛的信任建立），也是你Skill工程能力的展示品。
**九十天动作：** 按你自己CURRENT-STATE里的优先级第5条做"可替换数据模板"，之后冻结功能，作为启动营的赠品或前置钩子使用。不再投入新开发。

## 16.6 PowerClaw（电力）：判决＝降级为方案模板

**真实状态：** 方案与定价体系完整，无签约，依赖的采购结构（央企产品单）你现在进不去（第15.3节）。
**九十天动作：** 方案归档为《电力行业解决方案模板》，随提案调用；停止为它做任何新开发与新内容；国网关系维持在培训层。

## 16.7 EmotionClaw（171情绪客服）：判决＝降级为技术资产

**真实状态：** V2.0技术文档（Anthropic 171情绪分类加PAD三维模型），无产品无客户。
**九十天动作：** 归档。它的正确形态可能不是独立产品，而是派活里数字员工的情绪模块与你课程里的一节亮点内容（"AI怎么读懂客户情绪"是极好的课堂素材）。

## 16.8 PowerOffice（2.5D数字员工平台）：判决＝封存并入派活

**真实状态：** PRD与20员工编制、2.5D等距UI概念，与派活功能高度重叠。
**九十天动作：** 创意部分（2.5D可视化、员工人格化）作为派活的远期功能构想进停车场，独立产品线关闭。两个数字员工平台是自我竞争。

## 16.9 AI Memory Assistant：判决＝止损重定义

**真实状态：** 20万外包，质量不合格，维权中。
**九十天动作：** 技术顾问评估残值后三选一（修复、重做、核销），设止损上限再投入不超过5万。产品方向重定义：第一个用户是你自己（客户档案与商业记忆的本地化，第12.3节），先做成你自用的内部工具，验证后再谈商业化。**情绪账与财务账分开：维权按法律程序走或放下，不再占用深夜带宽。**

## 16.10 龙虾框架与龙虾盒子：判决＝保持（履约限定）

**真实状态：** 框架已进课纲（企业培训的技术底座），盒子6999元/台与360绑定。
**九十天动作：** 已有承诺履约到位；盒子销售完全交给360渠道，你只提供你已写好的邀约与沙龙SOP包（换分成条款，第15.2节）；不主动压货、不建自有售后。

## 16.11 CommunityClaw（社区生态）：判决＝封存

**真实状态：** 构想完整，未启动，依赖的地产资源在贬值周期。
**九十天动作：** 进停车场。地产人脉的正确用法改为渠道（第8.3节低估一）：物业公司与社区连锁是"超级店长"类交付和启动营的获客渠道，不是新产品的理由。

## 16.12 视觉与影视接单（白墨线）：判决＝角色转换

**真实状态：** 5万级艺术片报价能力，但交付吃你的时间且不在三条曲线上。
**九十天动作：** 按15.7节执行：谈单可以、交付退出、分成书面化。

十二条线判决后，你的注意力从十二个方向收拢到两个加倍项。这张表的执行难度不在理性上（你看完会同意），在情绪上：每一条降级和封存都像亲手关掉自己的孩子。所以给一个心理装置：**封存不是死刑，是排队。** 停车场里的东西每季度有一次申诉机会，条件只有一个：它能直接服务三条曲线之一。
