# 第九章 短板：真短板、不用补的短板、以及补法总纲

## 9.1 五块真短板（必须补，但补法各不相同）

**短板一：组织能力（用人）。** 你管理AI是大师级，管理人几乎是空白。数据里唯一的"团队"痕迹是学生贺文宇负责商业对接，以及外包踩坑。你的方法论里"把高手经验搬进组织"讲得头头是道，你自己的组织人数是一。补法：不是招一堆人，是先补"一个人"：一名交付助理（把你的验收标准喂给他，用你训练公众号大师的流程训练他），六个月内让他能独立完成60分的交付初稿。**补齐方式：自建，因为这是你规模化的必经之路，外包不了。**

**短板二：技术验收能力。** 你不需要会写代码，但你目前连"外包交付的代码是好是坏"都无法判断，这在你数十万级的产品投入面前是裸奔（R4）。补法：**外购，不自建。** 找一位信得过的兼职CTO级顾问（可以是远程的、按次付费的），所有技术采购过他的手。你去学编程是最差解，违反你自己的"贵的场景做工具，便宜的场景做培训"原则：你的时薪做销售是最贵的，做程序员是最便宜的。

**短板三：财务与法务的验收能力。** 合同AI起草你签字、报价拍脑袋、公司与家庭账目边界不明（R8、R9）。补法：**外购。** 本地律师年度框架（合同模板年检加物料合规），代账升级为有管理报表的财务服务，让你每月看到四个数：现金余额、应收、月度固定成本、各产品线毛利。你给企业讲ROI账本，先给自己装一个。

**短板四：深度输入的纪律。** 第4.5节与细节五：输入枯竭中。补法：**制度化，不靠自觉。** 每周半天"输入日"写进日历（拆解一个对手产品、精读一份行业报告、或深访一个客户的业务细节），像客户会议一样不可侵犯。你的课件质量就是你的输入质量的滞后指标，滞后大约一个季度。

**短板五：拒绝的能力。** 每个会面催生新构想、每个客户要求都接、优惠随口给。这是你产品线过散与定价疲软的共同根源。补法：**用制度替代意志力。** 想法停车场（细节八）、价格政策（第十二章）、以及一句你需要练习的话术："这个需求很好，放到下一期规划里评估。"

## 9.2 三块不用补的短板（接受它，绕过它）

**不补一：技术原理。** 端口、代理、模型参数，你不懂就不懂了。你的价值在翻译层和组织层，不在实现层。继续用AI当外骨骼，把验收外购（短板二）即可。

**不补二：学术规范。** 你曾要求"5万字ISC级别论文"，说明你对学术体系有向往。放弃它。你的话语权路径是商业出版加行业标准，不是学术发表。你已经有一本合著书，第二本自己的书比任何论文都值钱。

**不补三：内向者的深度社交面。** 你的社交模式是舞台型加饭局型，高效但宽而浅。不需要改成深度关系型，只需要在宽社交里筛出三五个"人形反驳者"（见9.3）。

## 9.3 一个特殊配置：人形反驳者委员会

第5.6节的孤独问题，解法不是交朋友，是建机制。你需要三种反驳者，各一到两人：

1. **商业反驳者**：认知水平能压住你的企业家或投资人（你的润米、360人脉里找），每季度一次两小时，只干一件事：攻击你的季度计划。
2. **技术反驳者**：短板二的兼职CTO顾问兼任，攻击你的产品决策。
3. **生活反驳者**：配偶或老友，有权对你的日程说"太满了"，并且你承诺听。

你在派活平台里设计了"AI会议按提案→反向验证→决策→执行强制收敛"，说明你完全懂反向验证的价值。把这个机制从产品里搬到人生里。
