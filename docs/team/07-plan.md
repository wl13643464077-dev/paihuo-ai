# 联网工具与技能执行热修计划

## 切片 1：联网员工真正完成 WebSearch

任务: 数字员工和联网工具在无头模式下只获准调用 WebSearch，并且只有真实成功
结果才能继续生成交付。

范围: `app/llm.py`、对应单元测试；不开放文件、命令、浏览器或任意 URL 访问权。

验收标准: 命令同时包含工具白名单和非交互预授权；成功/失败工具结果只记聚合；
零成功结果抛稳定错误，不能把供应商权限声明交给最终模型。

验证方式: 聚焦单测；修复前/后生产最小能力探针只输出 tool_use/result 聚合。

## 切片 2：今日必发不再假成功

任务: 热点扫描只在至少存在一个结构完整选题时成功，空结果和权限/受限声明失败。

范围: `app/growth.py` 与独立质量门测试；不改变 UI 视觉和计费合同。

验收标准: 空/坏格式/权限声明不保存且进入既有失败退款链；有效结果最多保留 3 条。

验证方式: 模拟模型返回的 RED/GREEN 单测；正式域名真实热点扫描。

## 切片 3：升级前阻断不兼容执行器

任务: 发布预检验证 `--allowedTools`、`--permission-mode` 与既有隔离旗标。

范围: `deploy/preflight.py`、`tests/test_deploy_hardening.py`。

验收标准: 当前 Claude CLI 通过；缺任一新增权限旗标的旧执行器 fail closed。

验证方式: 发布预检聚焦测试与新 release 的 preflight。

## 切片 4：线上四路验收

任务: 发布后分别验证数字员工、今日必发、线索雷达和工具箱通用只读入口。

范围: 新不可变 release、正式域名；不读取/输出业务正文，不留下测试账号或伪线索。

验收标准: WebSearch 成功计数大于 0；热点不再出现权限声明；线索只交付可追溯
原帖或明确失败退款；员工任务实际加载私有能力/技能并保留权限隔离。

验证方式: 聚焦/全量测试、发布门禁、正式域名浏览器/API 验收和服务/备份检查。
