## 2. 数字员工能力升级（来自「内容流水线」v3 交接包）

- 趋势官：选题五维打分（热度30/痛点20/转发收藏20/相关20/时效10）+ 本企业近 30 天选题自动去重（`registry.recent_topics`）。
- 撰稿人：人性自检（开头禁用语、≥2 个人性杠杆、回到你的店、收藏点、转发句）+ 去 AI 味硬规则；输出 `self_check`。
- 分发官：一核三版——先写 `core_card`，抖音（口播 180–300 字）/视频号（300–480 字 + 转发理由）/小红书（300–600 字 + 6–9 张图文卡规格）各自重写；新增 `script`、`first_comment`、`forward_reason`、`cards` 字段。
- 平台规格表按 v3 规范更新；新增 7 项可开关能力。

- `app/xhscards.py`：分发官给出的卡片规格本地 PIL 渲染成 1080×1440 PNG（封面大字结论 / 事实 / 步骤 / 避坑 / 收藏总结，5 套配色），零生图费用；字体缺失时降级为只出文字。

## 4. 部署注意

- 生产服务器需有中文字体（`/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc` 或 wqy；也可用 `PAIHUO_CARD_FONT` 指定），否则卡片降级为文字版，不影响其余功能。
- 老板自定义过分发官/撰稿人/趋势官提示词的企业仍用自己的模板；新字段缺失时体检照常运行，卡片不出。
- 按 PROJECT.md 走确定性 release 构建与冻结 staging 全量测试后才可进入 `deploy/upgrade.sh`。
