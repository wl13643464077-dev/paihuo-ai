# 交互与视觉设计锁定

## 设计方向

延续派活现有温暖、克制的老板工作台风格，不做大屏炫技，不使用虚假实时曲线。
首屏优先“需要老板处理什么”，其次是结果与效率，最后才是全量记录。

## 巡店工作台

- 左侧/顶部：门店与巡检基本信息；照片采用编号网格，可删除、补说明、放大。
- 中部：总体评分与高风险摘要；问题卡明确显示严重度、证据照片、整改动作。
- 右侧/下方：整改状态、负责人、期限、复查入口和完整时间线。
- 手机端按“信息 → 照片 → 问题 → 整改 → 复查”单列布局。

## 多轮协作

- 用“第 1 轮 / 第 2 轮”版本时间线替代“重做”负面表达。
- 当前交付下方固定出现“继续沟通（1点）”，反馈和补充材料并列。
- 历史轮次可展开、复制和导出；只有最新已完成轮次可继续。

## 老板看板

- 范围条固定在标题下，清楚显示当前企业/行业/时间段。
- 第一排为 4～6 个决策 KPI；第二排为风险与员工表现；第三排为最近交付和巡店。
- 颜色只表达语义：绿色完成、琥珀待处理、红色高风险、灰色无数据。
- 所有卡片都能解释口径；未接经营数据采用虚线空态和“接入数据”提示。

## 可访问性

- 按钮、筛选、输入均有可读 label；状态不只依赖颜色。
- 键盘可完成上传后的主要操作；图片缩略图有序号与说明。
- 减少动画，轮询期间保留草稿和滚动位置。

## schema52 巡店工作台深化

### 门店导入向导

- 顶部“批量导入门店”打开四步向导：下载模板、上传、预览、确认。
- 预览汇总 create/update/unchanged/warning/error；逐行展示门店编号和稳定错误码，
  手机号只显示脱敏值。
- 错误行不可提交；确认页明确本次新增/更新数量。
- 导入成功回到门店库，支持按门店编号/名称搜索和区域筛选。

### 标准化采集

- “本次巡店标准”先展示标准版本、来源层级和强制/推荐/运营图例。
- 每个拍摄槽位是一张卡：区域、构图、全景/近景、隐私提醒、必填标识、选择/重拍。
- 销售/员工/温度等数值项使用独立字段；文档证据与现场照片分区。
- 页面显示覆盖进度，例如“必拍 5/6、数据 3/4”；未完成项可直接定位。

### 数据对比

- 指标卡同时显示实际、目标、上期、同期和可信基准；缺项显示“待接入/无同期”，
  不显示 0。
- 来源、单位和期间与值同屏；行业推荐口径和企业目标标签不同。
