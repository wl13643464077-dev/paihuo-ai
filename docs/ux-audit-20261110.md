# 派活 体验走查与改进方案（2026-11-10）

走查范围：登录页、今天、派活（6 页）、门店（6 页）、获客（5 页）、我的（套餐、团队等）、店员手机版 `/staff`，以及手机宽度下的今天页和下达任务页。
走查方式：本地起一份空库，用平台管理员和新开的老板账号（餐饮行业、500 点）实际点过一遍。
没有覆盖：AI 真实出结果后的交付页、任务详情、巡店报告（本地没配模型）；店长、店员角色的权限视图；微信支付和短信登录。

严重程度：**高** = 用户会卡住、看不懂或对产品失去信任；**中** = 明显增加理解成本或操作步数；**低** = 打磨项。

## 二、其余问题与可执行方案

### A. 信息架构

**A1（高）门店没有自己的"家"。** 建门店、导入门店藏在"巡店"页右上角；其他 4 个页面都依赖门店，却都要用户自己找过去。
方案：在「门店」中转页顶部加一块"我的门店"（门店数、新建、批量导入、列表入口），把 `inspectionNewBranch` 和导入入口挪到这里；巡店页只保留"选门店去巡"。工作量约 1 天，纯前端。

**A2（高）四个看板重叠。** 数据驾驶舱、老板看板、员工产出、门店排行讲的是同一批数据，名字还互相打架（"老板看板"点进去叫"老板经营驾驶舱"）。
方案：保留「数据驾驶舱」作为唯一入口；门店排行并入它的"门店表现"区；老板看板里独有的"行业经营指标（待接入）"和"每个员工做了什么"作为驾驶舱的两个标签页；员工产出降为驾驶舱内的下钻页。旧路由保留并跳转。需要产品拍板后再做，约 3–4 天。

**A3（中）入口名和页面标题不一致。**

| 入口卡片 | 页面标题 | 建议统一为 |
|---|---|---|
| 巡店 | 区域经理巡店 | 巡店 |
| 老板看板 | 老板经营驾驶舱 | 见 A2 |
| 员工产出 | 员工产出总览 | 员工产出 |
| 内容审查 | 审查官的工作台 | 内容审查 |
| 定时发布 | 定时任务 | 定时发布 |
| 套餐 | 我的积分账户 | 套餐与点数 |
| 多位专家一起商量 | AI 结果型会议 | 多位专家一起商量 |

方案：标题以入口名为准，原标题里的角色感放到副标题。改之前先 grep `tests/` 里的断言。约半天。

**A4（中）行业名称两套叫法。** 找专家页是"餐饮行业"，巡店和看板的下拉是"餐饮产业部""便利店行业痛点数字员工"。
方案：下拉统一用"餐饮""便利店"这类短名；后端 `departments` 的展示名加一个 `short_label`，前端只读它。约半天。

**A5（低）顶部导航里"退出"悬在中间。** 桌面端 5 个入口之后隔一段空白才是"退出"，右边又是"在线"。
方案：退出和在线状态一起靠右，收进一个账号菜单（显示企业名 · 账号 · 余额 · 退出）。

### B. 用户流程

**B1（高）首次登录要输 4 次密码、登录 2 次。** 登录 → 再输一遍当前密码 → 新密码两遍 → 被踢回登录页再登一次。
方案：强制改密页不再要求当前密码（刚登录的会话本身就是凭证，可用一次性的改密令牌保证安全）；改完直接进首页，不重新登录。要改后端 `/auth/password`，需安全评审。约 1 天。

**B2（高）新手引导有四套。** 今天页顶部的"3 分钟上手"卡，加上"新手上路"里折叠的"开工四步""四步用人法""发布三件套"，共 14 步，内容还有重叠。而且"3 分钟上手"卡是登录后晚一拍才出现的，页面会跳一下。
方案：只留一条主线——上手卡 3 步做完后，同一位置换成"接下来 3 件事"（建门店、派第一个活、绑微信）；"四步用人法"改成找专家页里的一行提示；其余删掉。上手卡随首屏一起渲染，避免跳动。约 2 天。

**B3（高）开会选人要在近百个分组里找。** "多位专家一起商量"页把所有行业的全部小组平铺成 90 多行折叠项，餐饮老板要翻过汽车、药房、宠物的小组。
方案：默认只展开本企业所属行业的分组，其他行业收进"其他行业"；把"按议题自动选人"做成主按钮、手动勾选做成次要路径；页首的说明去掉"Top N""GO / NO-GO""单位经济反向验证"，改成"每位专家各出一个方案，互相挑毛病，最后给您一个做或不做的结论"。约 1 天。

**B4（中）下达任务页说"只需要三步"，实际列了 7 个编号区块。**
方案：页面只露 ①行业（按企业档案预填）②内容方向 ③提交；内容类型、配图、平台、风格、人设、管控程度收进"更多设置"，并记住上次的选择。余额不足的提示挪到提交按钮上方，而不是按钮下面。约 1 天。

**B5（中）数字人视频页一屏塞了 5 条流程。** 贴链接改写、门店一条龙（A/B/C）、开拍①–⑤、AI 带货视频，页面里有两个"开拍"按钮，还有"模式C""可灵""HeyGen""RunningHub""Seedance 2.5"这些供应商名。
方案：页首先让用户选"我要做什么"（老板口播 / 门店一条龙 / 带货短片），选完只显示那一条流程；供应商名换成能力描述（"会动的数字人""对口型"），具体引擎放进高级选项。约 3 天。

**B6（中）套餐页的购买路径长。** 选套餐 → 提交购买申请 → 等平台联系 → 线下到账 → 人工开通；页面上"提交购买申请"之后会发生什么、多久有人联系，没有说明。
方案：按钮下加一行"提交后 X 小时内顾问联系您，到账后点数立即到账"；提交成功后显示顾问联系方式和进度条。开通微信支付后自动切成扫码。约半天。

### C. 操作效率

**C1（中）中转页多一次点击。** 派活、门店、获客三个入口都先进一个卡片页，再点进具体功能；老板每天最常用的"派出去的活""巡店"都在第二层。
方案：中转页顶部加"最近用过"的 2 个入口；或桌面端鼠标悬停导航时直接展开子菜单。约 1 天。

**C2（中）筛选和搜索不记状态。** 巡店的行业下拉、看板的周期、任务列表的筛选，离开再回来都回到默认值。
方案：按账号存到 `localStorage`，读写都包 try/catch。约半天。

**C3（低）弹窗里的回车行为不统一。** 部分弹窗回车提交，部分表单（团队页的改密码、开租户）回车无效。
方案：凡是单一主操作的表单，统一包成 `<form>` 并处理 submit。

### D. 反馈机制

**D1（中）余额不足要到提交时才知道。** 数字人页写着"本单 12 点 · 余额 0 点"，按钮仍是可点的主色。
方案：余额不足时按钮改成"点数不够，去充值"，直接跳套餐页；各工具的按钮统一这个规则。约半天。

**D2（中）费用的写法不统一。** "（1点）""(0.2 点)""每人1点""+3点""💎 本单 18 点"几种格式混用，有的在按钮里，有的在按钮下。
方案：统一为按钮下方一行"本次 N 点 · 余额 M 点"，按钮文字只写动作。做成一个小组件，全站替换。约 1 天。

**D3（低）店员手机版空状态说"今天的活都做完了"。** 从来没被派过活的人也看到这句。
方案：没有任何历史任务时改成"还没有人给您派活"。

**D4（低）登录页的主按钮看着像不可用。** 没输入时"登录"按钮是很浅的黄色配灰字，对比度低。
方案：空表单时保持正常主色，点了再提示缺什么；或者把禁用态的文字对比度提到 4.5:1 以上。

### E. 视觉层级

**E1（中）空账号的今天页太空。** 三张卡各一行字，最重要的"下一步做什么"折叠在最下面。见 B2。

**E2（中）说明文字太长、太密。** 团队与权限、发布渠道、数字人页的页首说明都是一整段，夹着括号、箭头和斜杠。
方案：每页页首只留一句话（不超过 30 字）；其余改成字段旁的帮助提示或"了解更多"折叠。逐页改写，约 1 天。

**E3（低）图标全是 emoji。** 不同系统上渲染不一样，导航里的图标在 Windows 上会偏小、偏灰。
方案：5 个一级入口和主要按钮换成一套内联 SVG 图标；内容区的 emoji 可以保留。约 1 天。

**E4（低）驾驶舱的图表在全 0 时纵轴是"0 / 1 / 1"。**
方案：无数据时不画坐标轴，显示一句"这段时间还没有完成的活"。

### F. 组件一致性

**F1（中）称呼"您"和"你"混用。** 数据驾驶舱整页用"你"（"等你拍板""帮你找出"），其他页面用"您"。
方案：全站统一"您"，`cockpit.js` 和 `app/` 里对应的文案一并替换。约 1 小时。

**F2（中）标点全角半角混用。** 同一句里既有"，"又有","和":"，如"每天挑好今天该发的内容,照着发就行"。
方案：中文文案统一全角标点；写一个脚本扫描 `static/` 里中文字符相邻的半角 `,:;()`，人工确认后批量替换。约半天。

**F3（低）空状态的样式有三种。** 有的是居中灰字，有的是带边框的卡片，有的左对齐"暂时没有"。
方案：抽一个 `emptyState({icon, text, action})` 函数，全站统一成"一句话 + 一个按钮"。可以在做 A1、B2 时顺手完成。

**F4（低）平台管理员才用的词出现在通用文案里。** "租户""幂等开通""口径""历史总账""同批完成率""配置 r1"。其中一部分只有平台账号看得到，但老板看板里的"口径""历史总账""同批完成率""配置 r1"客户也看得到。
方案：老板看板的词逐个换成大白话（"历史总账"→"到现在还没处理的"，"同批完成率"→"这段时间派的活完成了多少"），"配置 r1"对客户隐藏。并入 A2 一起做。

**F5（低）无障碍。** 读屏器读不到顶部导航 5 个链接的名字，"批量导入门店"按钮也没有可读名称；`/favicon.ico` 返回 404。
方案：给导航链接和图标按钮补 `aria-label`；加一个 favicon。约 1 小时。

## 三、建议顺序

1. 本次高优先级 8 项合并后，先做 **A1、B2、B3**——这三项决定新老板头 10 分钟能不能走通。
2. 再做 **A3、A4、F1、F2、D2**——都是文案和一致性，风险低、见效快，可以一个 PR。
3. **A2、B1、B5** 需要产品或安全上的决定，先定方案再排期。
